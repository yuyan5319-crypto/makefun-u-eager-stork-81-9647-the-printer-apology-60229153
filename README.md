The Printer Apology: one original one-line apology from an office printer to the people who keep jamming it, feeding it cheap paper and swearing at it — 113 characters, with the punch at the very end.

> I'm sorry I ate your report — but you fed me bargain paper and a staple, then swore at me like I chose this life.

## Run it

```sh
node main.ts
```

The program writes the apology to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout. It refuses to run if the apology is not 1–120 characters, so the gate can never see an invalid entry.
